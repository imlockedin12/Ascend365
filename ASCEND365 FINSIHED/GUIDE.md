# ASCEND 365 — Personal Life Transformation App

> **Platform note (updated):** ASCEND 365 is built **mobile-first for iPhone**. It installs as a home-screen web app (Safari → Share → Add to Home Screen) and runs full-screen and offline. The Windows PC is only used to **test** it in a browser before installing on the phone — on desktop it shows inside a phone-sized frame. Data lives on the device; export/import backups move it between devices.
>
> **Social Intelligence note:** the conversation partner runs **offline from rules, with no AI service or API key**. It still takes typed, multi-turn replies and coaches on flow, follow-ups, open vs. closed questions, sharing, naturalness, confidence and respect.


## 1. Project Overview

Build a premium, highly polished, satisfying personal development application called **ASCEND 365**.

This is not a basic habit tracker, to-do list, questionnaire, or motivational app.

It is a **personal operating system for a complete one-year life transformation**, combining habit tracking, goal management, fitness progression, business productivity, social intelligence training, analytics, and a structured 365-day roadmap.

The entire experience should feel like leveling up a character in a game, except the character is the user in real life.

**Transformation period:**
November 20, 2026 → November 20, 2027.

The app must show the exact number of days completed, days remaining, progress throughout the full year, and milestones achieved.

The target is **iPhone (mobile-first)**. Windows desktop is only for testing in a browser before installing on the phone.

The user should be able to launch the application instantly from their computer without downloading new files every day.

# 6. User Interface and Visual Direction

The UI must feel significantly more premium and polished than a basic productivity dashboard.

### Visual direction

- Dark mode as the primary theme.
- Deep charcoal and near-black backgrounds.
- Tasteful purple/violet accent colors.
- Subtle gradients and soft lighting.
- Premium typography.
- Rounded but restrained card design.
- Well-organized spacing.
- Smooth animations and responsive interactions.
- Clear visual hierarchy.
- Minimal clutter.
- Beautiful charts and progress indicators.

Think of a combination of a premium fitness app, a modern personal analytics dashboard, and the progression system of a well-designed RPG.

The experience is designed for the phone first; on a Windows monitor it is shown in a phone-sized test frame.

### Make interactions satisfying

When completing a task:

1. The checkbox responds instantly.
2. A smooth animation confirms completion.
3. The progress bar fills.
4. XP increases.
5. The task displays a completed state.
6. If a meaningful milestone is reached, show a tasteful celebration.

Use subtle sounds and haptic feedback only when supported and enabled by the user.

Allow reduced motion and disabling sounds.

Do not overwhelm users with confetti or animations after every tiny action.

# 10. Development Expectations

Build the app as a complete, coherent product rather than a collection of disconnected screens.

Start by establishing a consistent design system, navigation, data model, and persistent state.

Prioritize a polished and functional implementation of the Dashboard, My Day, Year Roadmap, and Goals system.

Then implement Fitness, Business, Tennis, Social Intelligence, and detailed Insights.

Every visible control must perform a real action. Do not include fake buttons, meaningless charts, or dead-end pages.

Use realistic sample data only when clearly identified as demonstration data.
